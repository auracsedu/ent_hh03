# 시작하기

vscode에서 프로젝트를 열고, 아래 명령어를 실행하세요.
(명령어 대신 [VS Code 작업으로 실행하기](#vs-code-작업으로-실행하기)의 `환경 설정` 작업을 써도 됩니다.)

Windows:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
.\setup.ps1
```

MacOS:

```bash
chmod +x ./setup.sh
./setup.sh
```

# 테스트 돌리기

터미널에서 다음을 붙여넣으면 테스트가 됩니다.

## 전체 테스트하기

```bash
python -m pytest
```

## 특정 번호만 테스트하기

```bash
python -m pytest -k problem_01
```

# VS Code 작업으로 실행하기

터미널 명령어 대신 VS Code 메뉴 `Terminal > Run Task...` (한국어 UI: `터미널 > 작업 실행...`)에서 아래 작업을 선택해도 됩니다.

| 작업                 | 하는 일                                                                       |
| -------------------- | ----------------------------------------------------------------------------- |
| `환경 설정`          | `setup.ps1` / `setup.sh` 실행 (Windows에서는 실행 정책 설정 없이 바로 됩니다) |
| `전체 테스트`        | `python -m pytest`                                                            |
| `특정 번호만 테스트` | 문제 번호를 입력받아 `python -m pytest -k problem_번호` 실행                  |

# 어느 세트를 풀까요

3주차 숙제는 `he03`와 `hh03`(이 세트) 두 가지가 있고, **둘 중 하나만** 풀면 됩니다.
어느 쪽이든 세 시간 정도 걸리게 짜여 있습니다.

- `hh03` — 문제가 5개지만 하나하나가 더 깁니다. 수업 문제 9번까지 풀었고 백트래킹
  (extra 2)을 제대로 붙잡아 보고 싶으면 이쪽을 고르세요.
- `he03` — 문제 하나하나가 작은 대신 문제 수가 8개입니다. 수업에서 재귀 문제(5번
  이후)를 끝까지 못 갔거나, 재귀가 아직 손에 익지 않았으면 그쪽을 고르세요.

어느 쪽을 골라도 3주차에 배운 내용(위치 i 를 직접 움직여 문자열 메서드 만들기,
재귀의 종료 조건과 "작은 문제에 맡기기", 쓴다 / 안 쓴다로 나누기, 고른 것을
되돌리기)을 전부 쓰게 됩니다.

# 문제 목록 (3주차 숙제: 어려운 세트)

각 파일 맨 위의 설명을 읽고, `raise NotImplementedError` 를 지우고 그 자리에 코드를
쓰세요. 2주차 숙제처럼 함수를 완성하는 형식이고, 테스트가 함수를 직접 불러 돌려준
값을 검사하므로 `print` 가 아니라 `return` 을 써야 합니다. 1 은 수업 문제 1~3 의
연장(직접 만들기)이고, 2~5 는 재귀를 한 계단씩 올라가 백트래킹까지 갑니다.

| 파일            | 주제                              | 핵심                                                   |
| --------------- | --------------------------------- | ------------------------------------------------------ |
| `problem_01.py` | 문자열 직접 다루기 (함수 3개)     | 양 끝 인덱스, 오른쪽부터 세 자리씩, 조각 모으기 (토큰) |
| `problem_02.py` | 중첩 리스트 세 가지 (함수 3개)    | 재귀가 숫자 / 구조 / **인자를 하나 더** 들고 내려갈 때 |
| `problem_03.py` | 고르는 재귀 (함수 2개)            | 같은 것을 여러 번 쓰는 "쓴다", 상태를 인자로 들고 가기 |
| `problem_04.py` | N-퀸 (함수 3개)                   | **`append` / `pop` 백트래킹**, 복사본 넣기             |
| `problem_05.py` | [도전] 스도쿠 풀기 (함수 3개)     | 2차원 판에서 넣고 되돌리기, 실패하면 원상 복구         |

## 다 못 풀어도 괜찮습니다

위에서부터 순서대로 푸세요. `problem_05.py` 는 도전 문제라 시간이 꽤 걸립니다.
1~4번까지 제대로 풀었으면 숙제는 충분히 한 것입니다. 5번은 4번의 `append` / `pop`
을 `board[r][c] = d` / `board[r][c] = 0` 으로 바꾼 것이니, 4번을 먼저 끝내고 그
모양을 그대로 옮기세요. 막힌 지점을 들고 오면 됩니다.
